1.1 颜色理论基础

颜色理论是研究颜色的科学与艺术，它帮助我们理解颜色的性质、相互关系和使用方法：

颜色的三个基本属性
属性定义在设计中的作用
色相（Hue）颜色的名称，如红色、蓝色、绿色等决定颜色的类型和特征

🔧 第二部分：颜色代码转换详解

2.1 RGB颜色模型

RGB（Red, Green, Blue）是最常见的颜色模型，用于描述通过红、绿、蓝三原色光线混合得到的颜色。在计算机显示中，RGB值的范围通常是0-255：

RGB示例 
/* RGB表示法 */
.color1 {
  background-color: rgb(255, 0, 0);     /* 红色 */
}

.color2 {
  background-color: rgb(0, 255, 0);     /* 绿色 */
}

.color3 {
  background-color: rgb(0, 0, 255);     /* 蓝色 */
}

.color4 {
  background-color: rgb(255, 255, 255); /* 白色 */
}

.color5 {
  background-color: rgb(0, 0, 0);       /* 黑色 */
}

/* 带透明度的RGB */
.color6 {
  background-color: rgba(255, 0, 0, 0.5); /* 半透明红色 */
}

.color7 {
  background-color: rgba(0, 0, 255, 0.3); /* 30%透明度蓝色 */
}
RGB转换公式
  • HEX到RGB：#RRGGBB → rgb(R, G, B)
  • RGB到HEX：rgb(R, G, B) → #RRGGBB
  • RGB到HSL：需要复杂的数学计算，使用工具更方便

2.2 HEX颜色代码

HEX（Hexadecimal，十六进制）是RGB的一种简写方式，使用6位十六进制数表示颜色。它在Web开发中非常常见：

HEX示例 
/* HEX表示法 */
.color1 {
  background-color: #ff0000;   /* 红色 */
}

.color2 {
  background-color: #00ff00;   /* 绿色 */
}

.color3 {
  background-color: #0000ff;   /* 蓝色 */
}

.color4 {
  background-color: #ffffff;   /* 白色 */
}

.color5 {
  background-color: #000000;   /* 黑色 */
}

/* 3位HEX简写（重复每个字符）*/
.color6 {
  background-color: #f00;      /* 等同于 #ff0000 */
}

.color7 {
  background-color: #0f0;      /* 等同于 #00ff00 */
}

.color8 {
  background-color: #00f;      /* 等同于 #0000ff */
}

/* 8位HEX（包含透明度）*/
.color9 {
  background-color: #ff000080; /* 红色，50%透明度 */
}

.color10 {
  background-color: #0000ff4d; /* 蓝色，30%透明度 */
}

2.3 HSL颜色模型

HSL（Hue, Saturation, Lightness）用色相、饱和度和亮度来表示颜色，与RGB相比更直观：

HSL参数说明
参数范围单位描述
色相（Hue）0-360度（°）颜色的类型，0°=红色，120°=绿色，240°=蓝色
饱和度（Saturation）0%-100%%颜色的纯度，0%为灰色，100%为纯色
亮度（Lightness）0%-100%%颜色的明暗，0%为黑色，50%为正常，100%为白色
HSL示例 
/* HSL表示法 */
.color1 {
  background-color: hsl(0, 100%, 50%);     /* 红色 */
}

.color2 {
  background-color: hsl(120, 100%, 50%);   /* 绿色 */
}

.color3 {
  background-color: hsl(240, 100%, 50%);   /* 蓝色 */
}

.color4 {
  background-color: hsl(0, 100%, 25%);    /* 深红色 */
}

.color5 {
  background-color: hsl(0, 100%, 75%);    /* 浅红色 */
}

.color6 {
  background-color: hsl(0, 0%, 50%);      /* 灰色（饱和度为0）*/
}

/* 带透明度的HSL */
.color7 {
  background-color: hsla(0, 100%, 50%, 0.5); /* 半透明红色 */
}

.color8 {
  background-color: hsla(240, 100%, 50%, 0.3); /* 30%透明度蓝色 */
}

2.4 CMYK颜色模型

CMYK（Cyan, Magenta, Yellow, Key）主要用于印刷行业。它是一种减色模型，通过不同比例的青、品红、黄和黑墨的组合来表示颜色：

CMYK特点
  • 用于印刷：适用于纸张、杂志、包装等印刷品
  • 减色模型：颜色越多，结果越暗
  • K代表黑色：Key（关键色）通常指黑色
  • 范围：每个通道0%-100%

2.5 转换公式

以下是常见的颜色代码转换公式和方法：

颜色转换JavaScript代码 
// HEX到RGB转换
function hexToRgb(hex) {
  // 移除#号
  hex = hex.replace('#', '');
  
  // 如果是3位简写，转换为6位
  if (hex.length === 3) {
    hex = hex.split('').map(c => c + c).join('');
  }
  
  const r = parseInt(hex.substring(0, 2), 16);
  const g = parseInt(hex.substring(2, 4), 16);
  const b = parseInt(hex.substring(4, 6), 16);
  
  return `rgb(${r}, ${g}, ${b})`;
}

// RGB到HEX转换
function rgbToHex(r, g, b) {
  return '#' + [r, g, b].map(x => {
    const hex = x.toString(16);
    return hex.length === 1 ? '0' + hex : hex;
  }).join('');
}

// HSL到RGB转换
function hslToRgb(h, s, l) {
  s /= 100;
  l /= 100;
  
  const c = (1 - Math.abs(2 * l - 1)) * s;
  const x = c * (1 - Math.abs(((h / 60) % 2) - 1));
  const m = l - c / 2;
  
  let r, g, b;
  
  if (h >= 0 && h < 60) {
    [r, g, b] = [c, x, 0];
  } else if (h >= 60 && h < 120) {
    [r, g, b] = [x, c, 0];
  } else if (h >= 120 && h < 180) {
    [r, g, b] = [0, c, x];
  } else if (h >= 180 && h < 240) {
    [r, g, b] = [0, x, c];
  } else if (h >= 240 && h < 300) {
    [r, g, b] = [x, 0, c];
  } else {
    [r, g, b] = [c, 0, x];
  }
  
  r = Math.round((r + m) * 255);
  g = Math.round((g + m) * 255);
  b = Math.round((b + m) * 255);
  
  return `rgb(${r}, ${g}, ${b})`;
}

// 使用示例
console.log(hexToRgb('#ff0000'));  // rgb(255, 0, 0)
console.log(rgbToHex(255, 0, 0));   // #ff0000
console.log(hslToRgb(0, 100, 50));  // rgb(255, 0, 0)

3.3 颜色搭配方案

选择合适的颜色搭配方案对设计至关重要。以下是一些常见的颜色搭配方案：

常见颜色搭配方案
方案名称描述特点示例
单色配色使用同一色相的不同明度和饱和度简洁、统一主色 + 深色 + 浅色
类似配色使用色轮上相邻的颜色和谐、协调蓝色 + 绿色 + 蓝绿色
补色配色使用色轮上相对的颜色对比强烈、醒目红色 + 绿色，蓝色 + 橙色
三色配色使用色轮上均匀分布的三个颜色丰富、活泼红色 + 黄色 + 蓝色
四色配色使用两组补色平衡、多样红色 + 绿色 + 蓝色 + 橙色
中性配色使用黑、白、灰等中性色稳重、专业黑色 + 白色 + 灰色

3.4 无障碍设计中的颜色应用

在Web设计中，确保颜色的可访问性非常重要。以下是一些无障碍设计的颜色最佳实践：

无障碍颜色最佳实践
  • 对比度：确保文本与背景有足够的对比度（至少4.5:1用于正常文本，3:1用于大文本）
  • 色盲友好：避免仅使用颜色来传达信息，添加图标、图案或文本标签
  • 色彩丰富性：为色盲用户提供替代的视觉线索
  • 避免颜色组合：避免红/绿、棕/绿等难以区分的颜色组合
  • 使用工具：使用颜色对比度检查工具验证设计
WCAG指南：Web内容无障碍指南（WCAG）建议文本和背景颜色的对比度至少为4.5:1。你可以使用WebAIM对比度检查器来测试你的颜色组合。

4.1 实用技巧

颜色转换实用技巧
  • 使用变量：在CSS中使用变量来管理颜色，便于后续修改和维护
  • 颜色命名：为颜色变量使用语义化的名称（如--primary-color，而非--color-1）

  • 考虑可访问性：始终确保颜色对比度符合无障碍标准
  • 测试颜色：在不同的设备和环境下测试颜色的显示效果

常见问题
问题原因解决方案
颜色在不同浏览器中显示不同浏览器对颜色的渲染差异使用标准的颜色格式，如HEX或RGB
颜色在打印时变色屏幕RGB和打印CMYK的差异为打印准备专门的CMYK颜色值
