8. MD5/SHA哈希加密工具 使用次数：8,765次

使用频率：⭐⭐⭐⭐ | 推荐工具：立即使用 →

支持的算法
  • MD5：128位哈希，速度快但已不再安全
  • SHA-1：160位哈希，已被证明不安全
  • SHA-256：256位哈希，目前推荐使用
  • SHA-512：512位哈希，安全性更高
安全提醒：MD5和SHA-1已不再安全，仅用于非安全相关的场景。安全应用请使用SHA-256或SHA-512。
使用场景
  • 密码存储：配合salt值存储用户密码（建议使用SHA-256）
  • 数据完整性：验证数据是否被篡改
  • 文件校验：为文件生成唯一指纹用于文件对比
  • 缓存标识：为数据生成唯一哈希值用作缓存键
代码示例
// Node.js 中使用crypto模块
const crypto = require('crypto');

// MD5加密
const md5 = crypto.createHash('md5').update('hello').digest('hex');
// 输出：5d41402abc4b2a76b9719d911017c592

// SHA-256加密
const sha256 = crypto.createHash('sha256').update('hello').digest('hex');
// 输出：2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
