```javascript
// 将图片转换为Base64
async function imageToBase64(file) {
  return new Promise((resolve) => {
    const reader = new FileReader();
    reader.onload = () => resolve(reader.result);
    reader.readAsDataURL(file);
  });
}

// 使用
const base64String = await imageToBase64(imageFile);
// 输出：data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...
```

const express = require('express');
const app = express();

app.post('/upload', (req, res) => {

**注意：** 这个转换在传输小文件时很方便，但对于大文件（>1MB）会增加33%的大小，建议使用分块传输。

### 🔴 陷阱4：语言过于僵硬，缺乏人类特性

**AI典型表现：**
```

```

**问题：** 语言生硬，缺乏人类的表达方式。

**解决方案：**
```✅ **改进版：**
在我们开发用户认证系统时，遇到了一个棘手的问题：如何在分布式系统中安全地传输用户身份信息？

传统的Session方式在微服务架构下很难维护，而JWT（JSON Web Token）完美地解决了这个问题。

**为什么我们选择JWT？**
- **无状态**：服务器不需要存储Session，减轻服务器压力
- **自包含**：Token本身包含所有用户信息，无需查询数据库
- **安全**：使用数字签名防止篡改
- **灵活**：可以在多个服务之间共享

**但是要注意：** JWT一旦签发就无法撤回，所以过期时间要设置合理（我们通常设置为2小时）。
```

**关键改进：**
- ✅ **使用"我们"** - 表示集体经验
- ✅ **提问形式** - "如何解决...?", "为什么...?"
- ✅ **强调观点** - "完美解决", "很难维护"
- ✅ **注意事项** - "但是要注意..."
