📖 详细使用教程

第一步：输入文本

在左侧的文本输入框中输入或粘贴您要加密的文本内容。可以是任意字符串，包括中文、英文、数字、特殊字符等。也可以从示例下拉框中选择常见的示例文本进行测试。

第二步：选择加密算法

我们提供三种常见的哈希算法：

  • MD5：生成32位（128位）的哈希值，速度快但安全性较弱
  • SHA1：生成40位（160位）的哈希值，安全性中等，已逐渐被淘汰
  • SHA256：生成64位（256位）的哈希值，安全性强，是当前推荐的算法
第三步：获取结果

点击对应的算法按钮后，加密结果会显示在右侧的输出框中。同时，系统会显示使用的算法类型和结果字符串的长度。您可以点击"复制结果"按钮将哈希值复制到剪贴板。

💡 实际应用场景

密码存储

在数据库中存储用户密码时，绝对不能存储明文密码。需要使用哈希算法对密码进行单向加密后存储。验证时，对用户输入的密码进行相同的哈希运算，比较结果是否匹配。注意：MD5和SHA1不适合密码存储，建议使用SHA256并加盐

数字签名

对文件或数据进行哈希运算，生成唯一的数字指纹。可以用于验证数据的完整性，检测数据是否被篡改。在数字签名和认证系统中，哈希算法是基础支撑。

数据唯一标识

为文件、数据库记录等生成唯一的标识符。通过对内容进行哈希运算，可以生成一个相对唯一的ID，用于检测重复数据或作为数据的唯一标识。

数据完整性验证

在数据传输或存储过程中，可以通过哈希值来验证数据是否被篡改。发送方计算数据的哈希值并随数据一起发送，接收方重新计算哈希值并与接收到的哈希值比较，确保数据完整性。

❓ 常见问题FAQ

A: 哈希算法（Hash）是单向的，即从输入计算到哈希值很容易，但从哈希值反推输入几乎不可能。哈希算法的核心特性是：
- 相同输入产生相同输出
- 不同输入（即使只差一个字符）产生完全不同的输出
- 不可逆（理论上）

加密算法（Encryption）是双向的，即使用密钥可以将明文加密为密文，也可以将密文解密为明文。加密的核心特性是：
- 使用密钥进行加密和解密
- 可逆（有密钥即可解密）
- 保护数据的机密性

A: MD5算法存在多个已知的安全漏洞：
- 碰撞攻击：研究人员已经可以构造出两个不同的输入，使它们产生相同的MD5哈希值
- 长度扩展攻击：MD5对较长的输入存在特定的攻击方式
- 雨表攻击：可以预先计算大量的哈希值，建立查找表，从而反推可能的输入

由于这些漏洞，MD5不再适合用于密码存储和安全相关的场景。对于需要高安全性的应用，建议使用SHA256或更强的算法，并配合加盐（Salt）技术。

A: 哈希算法的一个重要特性是固定输出长度。无论输入有多长，哈希值的长度总是固定的：
- MD5：32个字符（128位）
- SHA1：40个字符（160位）
- SHA256：64个字符（256位）

这是通过哈希函数的内部机制实现的。哈希函数会将输入数据分割为固定大小的块，然后进行多次压缩和转换，最终产生固定长度的输出。这种特性使得哈希函数可以处理任意长度的输入，同时保持输出的一致性。

A: 是的。哈希算法的一个基本特性是确定性：相同的输入总是会产生相同的哈希值。

正是因为这个特性，哈希算法可以用于：
- 密码验证：输入密码后计算哈希值，与数据库中存储的哈希值比较
- 数据完整性检查：对数据计算哈希值，稍后可以重新计算验证数据是否被修改
- 去重：通过哈希值检测重复数据

但是，这也意味着如果知道输入，就很容易验证哈希值是否匹配。因此，在密码存储等场景中，需要使用加盐（Salt）技术，为每个输入添加随机值，然后再计算哈希。

A: 要提高哈希算法的安全性，可以采用以下措施：
1. 使用更强的算法：选择SHA256或SHA3等更安全的哈希算法，避免使用MD5和SHA1
2. 加盐（Salt）：为每个输入添加唯一的随机值，然后计算哈希。这样即使两个用户的密码相同，哈希值也会不同
3. 多次迭代：对输入进行多次哈希运算（如1000次或更多），增加暴力破解的难度
4. 使用密钥：使用HMAC（Hash-based Message Authentication Code）等基于密钥的哈希算法
5. 添加椒盐：结合其他随机值，进一步增加复杂度

例如，安全的密码存储方式：SHA256(SHA256(password + salt) + pepper)

哈希算法比较

算法 输出长度 安全性 速度 常见用途
MD5 32字符（128位） 较弱 快 密码存储、数据完整性
SHA1 40字符（160位） 弱 快 数字签名、旧系统兼容
SHA256 64字符（256位） 强 快 密码存储、区块链、安全应用
SHA512 128字符（512位） 很强 中等 高安全性需求

常见用法

// MD5加密 输入: Hello, World! 点击"MD5" 输出: 65a8e27d8879283831b664bd8b7f0ad4 // SHA1加密 输入: Hello, World! 点击"SHA1" 输出: 0a0a9f2a6772942557ab5355d76af442f8f65e01 // SHA256加密 输入: Hello, World! 点击"SHA256" 输出: dffd6021bb2bd5b0af676290809ec3a53191dd81c7f70a4b28688a362182986f // 特点 - 相同输入总是产生相同输出 - 不同输入产生完全不同的输出（雪崩效应） - 不可逆，无法从哈希值推导出原始内容
