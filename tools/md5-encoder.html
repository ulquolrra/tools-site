使用说明

功能介绍：
  • MD5：32位字符串，常用于密码存储、数据完整性检查等
  • SHA1：40位字符串，比MD5更安全，但已逐渐被淘汰
  • SHA256：64位字符串，当前推荐的安全哈希算法
  • 特点：单向加密，不可逆，相同输入产生相同输出
  • 应用：密码存储、数字签名、数据验证等

哈希算法比较

算法 输出长度 安全性 速度 常见用途
MD5 32字符（128位） 较弱 快 密码存储、数据完整性
SHA1 40字符（160位） 弱 快 数字签名、旧系统兼容
SHA256 64字符（256位） 强 快 密码存储、区块链、安全应用
SHA512 128字符（512位） 很强 中等 高安全性需求

常见用法

// MD5加密 输入: Hello, World! 点击"MD5" 输出: 65a8e27d8879283831b664bd8b7f0ad4 // SHA1加密 输入: Hello, World! 点击"SHA1" 输出: 0a0a9f2a6772942557ab5355d76af442f8f65e01 // SHA256加密 输入: Hello, World! 点击"SHA256" 输出: dffd6021bb2bd5b0af676290809ec3a53191dd81c7f70a4b28688a362182986f // 特点 - 相同输入总是产生相同输出 - 不同输入产生完全不同的输出（雪崩效应） - 不可逆，无法从哈希值推导出原始内容

编程语言中的实现

// JavaScript const crypto = require('crypto'); crypto.createHash('md5').update('Hello').digest('hex'); crypto.createHash('sha1').update('Hello').digest('hex'); crypto.createHash('sha256').update('Hello').digest('hex'); // Python import hashlib hashlib.md5('Hello'.encode()).hexdigest() hashlib.sha1('Hello'.encode()).hexdigest() hashlib.sha256('Hello'.encode()).hexdigest() // PHP md5('Hello'); sha1('Hello'); hash('sha256', 'Hello'); // Java import java.security.MessageDigest; MessageDigest.getInstance("MD5").digest("Hello".getBytes()); MessageDigest.getInstance("SHA-256").digest("Hello".getBytes());
安全提醒： MD5和SHA1算法已不再被认为是安全的，请勿用于需要高安全性的场景。推荐使用SHA256或更高级的加密算法。
