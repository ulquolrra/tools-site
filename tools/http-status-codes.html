HTTP状态码说明

什么是HTTP状态码？

HTTP状态码是服务器用来响应客户端请求的三位数字代码。它告诉客户端请求是否成功，或者需要采取什么行动。

状态码分类
分类 范围 含义 示例
1xx 100-199 信息响应 - 请求已收到，继续处理 100 Continue, 101 Switching Protocols
2xx 200-299 成功响应 - 请求成功处理 200 OK, 201 Created, 204 No Content
3xx 300-399 重定向 - 需要进一步操作完成请求 301 Moved Permanently, 302 Found, 304 Not Modified
4xx 400-499 客户端错误 - 请求包含语法错误或无法完成 400 Bad Request, 404 Not Found, 403 Forbidden
5xx 500-599 服务器错误 - 服务器无法完成有效请求 500 Internal Server Error, 502 Bad Gateway, 503 Service Unavailable

注意事项：

  • 1xx和2xx表示请求处理正常
  • 3xx表示需要客户端进一步处理
  • 4xx表示客户端错误，需要修改请求
  • 5xx表示服务器错误，通常需要服务器端修复
  • 并非所有状态码都是标准的，有些是服务器自定义的
状态码最佳实践
API设计建议
  • 200 OK： GET、PUT请求成功，返回完整资源
  • 201 Created： POST请求成功，资源已创建，返回资源位置
  • 204 No Content： DELETE请求成功，不返回实体内容
  • 400 Bad Request： 客户端参数错误，需要修正
  • 401 Unauthorized： 需要身份验证，请提供凭证
  • 403 Forbidden： 无权限访问，拒绝请求
  • 404 Not Found： 资源不存在
常见错误处理
  • 500 Server Error： 服务器内部错误，检查日志
  • 502 Bad Gateway： 网关错误，检查代理配置
  • 503 Service Unavailable： 服务暂时不可用
  • 504 Gateway Timeout： 网关超时，检查后端连接
  • 429 Too Many Requests： 请求过多，限流保护
  • 405 Method Not Allowed： HTTP方法不支持
  • 415 Unsupported Media Type： 不支持的媒体类型
