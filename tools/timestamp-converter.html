❓ 常见问题FAQ

A: Unix时间戳（又称为POSIX时间戳或Epoch时间）是从1970年1月1日 00:00:00 UTC（称为Unix epoch）到当前时刻所经过的秒数总和。它是一种全球统一的时间表示方式，不受时区影响。时间戳是一个整数，通常用于计算机系统中的时间表示。

A: 秒级时间戳是从1970年1月1日到当前时刻的秒数，通常是10位数字（如：1625097600）。
毫秒级时间戳是从1970年1月1日到当前时刻的毫秒数，通常是13位数字（如：1625097600000）。

JavaScript等语言通常使用毫秒级时间戳（Date.now()返回的是毫秒数），而Unix/Linux系统通常使用秒级时间戳。

A: 1970年1月1日 00:00:00 UTC 被称为Unix epoch（Unix纪元）。这是计算机科学中的一个约定俗成的起始点。选择这个日期作为起点主要是因为：
1. 它接近第一台数字计算机ENIAC（1946年）的发明时间
2. 它位于计算机发展的早期阶段
3. 它在Unix操作系统的开发中被采用（1970年代初）
4. 从1970年开始计数可以确保时间戳是正数，便于计算机处理

A: 对于32位有符号整数表示的秒级时间戳，最大值是2^31-1 = 2,147,483,647，对应的时间是2038年1月19日 03:14:07 UTC。超过这个时间，32位系统会发生溢出，时间戳会变为负数（被称为2038年问题）。

但是，现代大多数系统已经使用64位整数表示时间戳，可以支持到大约292亿年，因此不需要担心溢出问题。

A: 不同的编程语言有不同的方法：

JavaScript：
Math.floor(Date.now() / 1000) - 秒级时间戳
Date.now() - 毫秒级时间戳

Python：
import time; int(time.time()) - 秒级时间戳
import time; int(time.time() * 1000) - 毫秒级时间戳

PHP：
time() - 秒级时间戳
round(microtime(true) * 1000) - 毫秒级时间戳

📚 时间戳基础知识

时间戳（Timestamp）是计算机科学中用于表示时间的一种方式。它将时间转换为一个数字，使得计算机可以方便地进行时间计算和比较。

时间戳的类型
类型 定义 位数 示例 对应日期
秒级时间戳 从1970年1月1日到现在的秒数 10位 1625097600 2021-06-30 16:00:00
毫秒级时间戳 从1970年1月1日到现在的毫秒数 13位 1625097600000 2021-06-30 16:00:00
微秒级时间戳 从1970年1月1日到现在的微秒数 16位 1625097600000000 2021-06-30 16:00:00
时间戳的用途
  • 时间计算：计算时间间隔、过期时间等
  • 排序：按时间顺序排列事件或数据
  • 数据库存储：以时间戳格式存储日期时间
  • 缓存控制：设置缓存的过期时间
  • 版本控制：为文件或数据添加时间戳版本
  • 唯一ID生成：结合其他信息生成唯一标识符
时间戳和日期格式的转换
  • 日期 → 时间戳：将可读的日期格式（如2024-01-01 12:00:00）转换为Unix时间戳
  • 时间戳 → 日期：将Unix时间戳转换为可读的日期格式
  • 时区处理：Unix时间戳基于UTC时间，需要根据需要转换为本地时间
  • 格式化：根据需要格式化日期输出（如YYYY-MM-DD HH:mm:ss）

时间戳是什么？

Unix时间戳（Unix timestamp）是从1970年1月1日（UTC/GMT的午夜）开始所经过的秒数。它是一种表示时间的方式，常用于计算机系统中。时间戳不受时区影响，是全球统一的时间表示方法。

常见用法

// 示例1: 时间戳转日期 输入: 1625097600 点击"自动转换"或"转日期" 输出: 2021-06-30 16:00:00 // 示例2: 日期转时间戳 输入: 2024-01-01 12:00:00 点击"自动转换"或"转时间戳" 输出: 1672534400000 (毫秒级) // 示例3: 当前时间 点击"当前时间" 输出: 当前的时间戳和日期 // 秒级 vs 毫秒级 1625097600 -> 秒级时间戳 (10位) 1625097600000 -> 毫秒级时间戳 (13位)
