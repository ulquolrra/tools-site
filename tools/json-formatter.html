📚 JSON基础知识

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，易于人类阅读和编写，同时也易于机器解析和生成。

JSON数据类型
数据类型 描述 示例
字符串 文本数据，必须用双引号括起来 "hello"
数字 整数或浮点数，不能有前导零 42, 3.14
布尔值 true 或 false true, false
null 空值 null
对象 无序的键值对集合，用大括号括起来 {"name": "John"}
数组 有序的值列表，用方括号括起来 [1, 2, 3]
JSON语法规则
  • 数据以键值对的形式表示，键和值之间用冒号分隔："key": value
  • 键必须是字符串，用双引号括起来
  • 不同的键值对之间用逗号分隔
  • 大括号 {} 保存对象，方括号 [] 保存数组
  • JSON不支持注释
  • JSON的字符串必须使用双引号，不能使用单引号

常见用法

// 输入压缩的JSON {"name":"张三","age":30,"skills":["JavaScript","Python","Java"]} // 点击"格式化"后 { "name": "张三", "age": 30, "skills": [ "JavaScript", "Python", "Java" ] } // 点击"压缩"后 {"name":"张三","age":30,"skills":["JavaScript","Python","Java"]}
