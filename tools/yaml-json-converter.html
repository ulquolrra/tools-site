使用说明

功能介绍：
  • YAML → JSON：将YAML格式内容转换为JSON格式
  • JSON → YAML：将JSON格式内容转换为YAML格式
  • 双向转换：支持两种格式的相互转换
  • 格式化：JSON输出支持美化格式

YAML vs JSON

YAML优点
  • 可读性强，适合人工编辑
  • 支持注释
  • 支持多行字符串
  • 常用于配置文件（如Kubernetes、Docker）
JSON优点
  • 计算机解析简单
  • 广泛支持（所有编程语言都有解析器）
  • 体积更小
  • 常用于API数据交换

常见用法

// YAML转JSON示例 输入 (YAML): name: John Doe age: 30 email: john@example.com hobbies: - reading - coding 点击"YAML → JSON" 输出 (JSON): { "name": "John Doe", "age": 30, "email": "john@example.com", "hobbies": ["reading", "coding"] } // JSON转YAML示例 输入 (JSON): {"name": "John Doe", "age": 30, "email": "john@example.com"} 点击"JSON → YAML" 输出 (YAML): name: John Doe age: 30 email: john@example.com
